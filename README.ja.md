# MORSE GAME for M5Stack

[English](README.md)

バージョン 0.1.1

モールス符号の送信（打鍵）を練習するためのゲームです。
M5Stack Core2 と M5Stack CoreS3-SE で動作を確認しています。

ゲームを始めると、画面にアルファベット 1 文字または英単語が表示されます。お題の下の時間バーがなくなる前に、モールスキーで正しい符号を打ってください。正しく打てると次のお題に進みます。間違えても、時間が残っていれば打ち直せます。時間内に正しく打てないとペナルティが 1 点付き、5 点（HARD レベルでは 3 点）たまるとゲームオーバーです。10 問（EASY では 5 問）正解するごとにステージが上がり、1 文字（ステージ 1）から 5 文字の単語（ステージ 5）まで出題されます。

必要なのはモールスキーだけです。縦振れ電鍵（ストレートキー）か、エレキーのパドル（キーヤー内蔵）を Grove ポートにつなぎます。

## キーの接続

| 機種 | ポート | ストレートキー / DIT パドル | DAH パドル |
|---|---|---|---|
| M5Stack Core2 | Grove Port A | GPIO 33 | GPIO 32 |
| M5Stack CoreS3 / CoreS3-SE | Grove Port B | GPIO 8 | GPIO 9 |

キーの接点は GND に落とします（ピンは内部プルアップ）。DIT と DAH のパドルは設定で入れ替えられます。

## 操作

3 つのボタンで操作します。ボタンの役割は画面の最下行にラベルで表示します。Core2 では画面の下にあるタッチボタン、CoreS3 ではラベルそのものがタッチボタンです。

| 画面 | 左 | 中央 | 右 |
|---|---|---|---|
| タイトル | 設定 | 開始 | |
| プレイ中 | | 中断 | |
| 中断中 | 終了 | 再開 | |
| 設定 | 次の項目（▼） | 前の値（◀） | 次の値（▶） |

設定項目:

| 項目 | 値 |
|---|---|
| KEY | STRAIGHT（ストレートキー）、IAMBIC-A、IAMBIC-B（パドル） |
| SPEED | 5〜40 WPM。キーヤーの速度。ストレートキーでは打ち始めの速度で、その後は打つ速さに自動で追従する |
| DIT / DAH | NORMAL、REVERSED（パドルの入れ替え） |
| LEVEL | EASY、NORMAL、HARD |
| VOLUME | 0〜10 |
| RESET | 設定を初期値に戻す（2 回押しで実行） |
| CLEAR SCORES | 全レベルのハイスコアを消す（2 回押しで実行） |
| EXIT | 保存して戻る |

レベルごとの違い:

| | EASY | NORMAL | HARD |
|---|---|---|---|
| 制限時間（ステージ 1〜5） | 8/12/16/20/24 秒 | 4/7/10/12/15 秒 | 3/5/7/9/11 秒 |
| ステージが上がるまでの正解数 | 5 | 10 | 10 |
| ライフ | 5 | 5 | 3 |
| ステージ 1 の出題 | 英字 | 英字と数字 | 英字と数字 |

設定とレベルごとのハイスコアはフラッシュメモリに保存されます。設定画面の右上には電池残量を表示します（充電中は先頭に「+」）。

このゲームは、2025年11月15日に開催された牧綾緑のフェスティバル（横浜緑ケ丘高等学校ホームカミングデー）における展示のために作成されました。

## ビルド

スケッチは [arduino-cli](https://arduino.github.io/arduino-cli/) でビルドします。
`sketch.yaml` に対象機種ごとのプロファイルを定義しており、ESP32 コアとライブラリは初回のビルド時に自動でインストールされます。

| プロファイル | 機種 | キーのピン |
|---|---|---|
| `core2` | M5Stack Core2 | GPIO 33, 32（Grove Port A） |
| `cores3` | M5Stack CoreS3 / CoreS3-SE（既定） | GPIO 8, 9（Grove Port B） |

ビルドの成果物はプロファイルごとに `build/<profile>` に置きます。

```sh
arduino-cli compile --profile core2 --build-path build/core2
arduino-cli upload  --profile core2 --build-path build/core2 -p <シリアルポート>
```

ESP32 コアは 2.0.17 に固定しています。3.x では M5Unified のスピーカータスクがスタックあふれを起こし、最初に音を鳴らしたときにクラッシュします。
